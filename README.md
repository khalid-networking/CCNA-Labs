# Basic Router Security Lab

## Objective
Configure basic router security settings in Cisco Packet Tracer.

## Topics Covered
- Console password
- Enable secret password
- Line VTY password
- SSH/Telnet basics
- Service password encryption
- Banner MOTD
- Secure access configuration

## Devices Used
- 1 Router
- 1 PC

## Commands Practiced
```bash
enable secret
line console 0
password
login
service password-encryption
banner motd
line vty 0 4
```

## Result
Successfully configured basic router security settings and verified secure remote access configuration.
